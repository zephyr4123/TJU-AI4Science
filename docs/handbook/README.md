# 协作手册：怎么和 agent 一起把活干好

这几个月本仓与内仓的活基本是「一个人 + coding agent（Claude Code、Codex）」干出来的。这里把其中**可复用**的做法写成教程：一个场景一章，每章四段——场景、做法、反例、本仓的真实例子（贴 issue、commit、`文件:行`，都能点开核对）。给项目组的每个人看，不分工程师还是研究者；agent 也读——它开工时读到的 `CLAUDE.md` 是规矩，这里是规矩背后的做法。

规矩本身只有一份，在 [`CLAUDE.md`](../../CLAUDE.md)；流程在 [`CONTRIBUTING.md`](../../CONTRIBUTING.md)。本手册不重复它们，只讲怎么做到。

## 怎么读

- 新人：01 → 09 → 03 → 02，然后领一条 issue 开干；其余遇到再看。
- 只用平台做课题的研究者：05、04 两章对你也成立——你和研究助理对话时同样适用。
- agent：不用整本读；`CLAUDE.md` 已经是规矩，某章被 issue 或评论点到时再读那一章。

每章的「本仓真实例子」写的是当时发生的事，issue 与 commit 都在；例子过时了改例子，做法过时了改做法，别留着不对的。本手册随外层仓的版本走（1.0.0 起），目前只在仓库里读，不进公开阅读版。
