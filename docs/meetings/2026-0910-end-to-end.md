## 结论

1. 内环这一格就是 autoresearch 的棘轮加护栏，这是选型时刻意的；差异化不在内环，在它两边和上面。
2. Claude 自查：纲领形状上有七个能力，实体上缺一层。run 以任务包为起点，端到端的起点是研究问题，任务包是中间产物。加实体：研究项目 → 任务包 × N → run × N → 论文。
3. 产品是论文，不是内环。
4. 记忆分两级：run 级（账本、笔记）已有；项目级（文献笔记、假设台账、跨 run 结论）是写作前提，Q-9 改写，0.2.0 之后第一优先。
5. 契约分两级：项目契约（研究问题、目标、论文形态）与实验契约（manifest）。manifest 的值由协调层动态产出，不在代码里调硬编码，也不为它重跑。
6. 文献检索建议走 `tools/` 学术 API 使引用可验（Q-11）；写作建议分节多次调用、图由 tools 出（Q-12）。
7. 代码结构现在重构：`framework/` 按概念分子包，依赖单向并用测试锁住（[#30](https://github.com/zephyr4123/TJU-AI4Science/issues/30)）。重构派 opus，fable 主线程只校验。
8. 09-22 那格做什么，等纲领与重构落地后再定 spec。
