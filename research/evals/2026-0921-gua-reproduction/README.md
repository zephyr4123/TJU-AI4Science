## 三句话

1. **复现的是什么**：一篇计算物理 × 机器学习交叉的论文——用物理信息神经网络解 Burgers 等六个偏微分方程，提出在优化器之后再做一次梯度投影（GUA）。平台接入了它最小的一组：官方仓库 commit `8bbbcd5`、随仓库附带的 Burgers 数据、`trainer.py` 一条命令的两个变体、上游自己写出的 `formal_metrics.json`。
2. **算力与能力**：算力是研究者租的 AutoDL 4090，一行 ssh 接进按人的清单，用镜像自带的环境。为跑通这条流程，平台新搭了复现流程、需求模板、文献格主文件、`download` 工具、「原码复现基线」与「复现性分析」两个能力，并在演练中补上了 `env add`、执行层会话额度、分析的 `--feedback`、对话锁与指南更新提醒。
3. **平台涌现**：助理自己找到仓库、把大题切成两行小题、定了 ±2σ 的统计口径、看日志诊断失败、自己起数字核对再通读抓文字错、给自己立验收线不无限重写、把中途新加的命令接进正在跑的活、结尾提醒关机——没有一条是提示词里写好的做法。

保留意见：这篇是预筛过的「好材料」；执行层写分析会编文字事实，靠助理通读兜底；「对上」是人判的。
